#  Simple Modal Popup

A basic and reusable modal component built with HTML, CSS, and JavaScript. Click a button to trigger a smooth popup window with a close option.

## ✨ Features

- Lightweight and responsive modal
- Open/close functionality
- Smooth animations
- Clean and simple design

## 🛠️ Tech Stack

- HTML  
- CSS  
- JavaScript

## 🔍 How It Works

1. Click the "Show Modal" button.
2. A modal window appears centered on the screen.
3. Click the "Close" button or outside the modal to close it.
